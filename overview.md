# LearnForRise — Project Overview

## Kya banana hai
Ek Sarkari Result type website, jiska purpose same hai — latest government job vacancies, results, admit cards, syllabus, answer key, admission updates ek jagah dena. Reference: sarkariresult.com.cm

Naam: **LearnForRise**

Design direction bilkul different rakhna hai reference se. Sarkari result wali sites zyadatar cluttered, ad-heavy, outdated design ki hoti hain. LearnForRise ka goal same content deliver karna hai but minimal, premium, clean experience ke saath.

## Core Goal
- Latest sarkari job vacancies, results, admit card, syllabus, answer key, admission info ek platform pe
- User ko information fast aur clutter-free mile
- Trust build ho premium look se (govt-related site hone ke wajah se trust zaroori hai)
- Mobile-first, kyunki zyada traffic mobile se aayega (tier 2/3 cities ke students)

## Tech Stack
- **Frontend:** Next.js (App Router)
- **Backend:** Node.js + Express + MongoDB
- **Animation libraries:** Framer Motion, Three.js, GSAP, Anime.js
- **Styling:** Tailwind CSS (recommended, design.md me detail hai)

## Design Philosophy
Minimal + premium + simple. Heavy animation nahi, purposeful micro-interactions. Poora detail `design.md` me hai.

## Future Scope (abhi build nahi karna, sirf architecture me flexibility rakhni hai)
- User accounts / saved jobs
- Push notifications for new jobs
- AI-based job recommendation
- Mock tests / quiz section
- Community / discussion forum

Isliye database schema aur folder structure aise design karo ki future features add karna easy ho — over-engineer mat karo abhi, but tightly coupled code bhi mat likho.
